# Transforming Workforce Insights: Strategic HR Analytics Dashboard

## Overview
This project is an interactive HR Analytics Dashboard built in Power BI to convert raw attendance and leave records into actionable workforce insights.

The dashboard helps analyze employee presence, work-from-home (WFH) behavior, and sick leave patterns through dynamic visual reports.

## Objectives
- Monitor employee attendance trends
- Track WFH and Sick Leave percentages
- Improve HR reporting efficiency
- Enable data-driven workforce planning
- Provide self-service dashboards for HR teams

## Tools & Technologies
- Power BI
- Power Query (M Language)
- DAX
- Microsoft Excel

## Dataset
HR attendance dataset containing:
- Employee attendance records
- Work From Home entries
- Sick Leave entries
- Date-wise workforce activity logs

## Data Preparation
Performed preprocessing using Power Query and Excel:

- Removed unnecessary rows/columns
- Promoted headers
- Changed data types
- Unpivoted monthly sheets
- Corrected formatting issues
- Combined sheets using parameters & custom functions

## KPIs Created
- Total Working Days
- Present Days
- Presence %
- WFH Count
- WFH %
- Sick Leave Count
- Sick Leave %
